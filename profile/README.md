<h1 align="center">Nacre</h1>
<p align="center">Mother-of-pearl. Colors shaped by your wallpaper.</p>

- [Nacre](https://github.com/nacre-desktop/nacre): a Quickshell desktop for Hyprland,
  with Settings, Colors, Welcome and optional AI/Brain components.
- [Orient](https://github.com/nacre-desktop/orient): the independent wallpaper-color
  engine, readable palettes and portable theme templates.

Both projects are in their **0.x development-preview** series. Installation,
version pins, tests and retained licensing are documented in each repository.
